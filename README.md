# Flight Tracker Hub

i want to create a flight ticket tracking website, where you can input a special code and see  details of customized flight. It should have an admin website that can allow me add custom flights and code to search flight. The admin website is different from the main tracking website. 

The main website would be showing EMIRATES as the company name alongside the attached Logo. It gives off a modern flight website look, A place to input the tracking code. When the tracking code is inputted, it opens a page that carries the flight details that the admin page has uploaded

for the admin page, Let it consist of the following things to input
Name of Passenger, Date of flight
From and To, 
An Additional option to add From and To (in cases of multi flight) 
Flight ticket
Tracking code
Time of Depart
Time of Arrival
Duration
class
seat
Gate
flight started (with option of yes and no)

all these are details to fill in and when done, it has an Upload button.  once clicked will be immediately uploaded on the main website. it can be edited and uploaded and changes takes on the main website. 

let the main website have a Book a flight option that takes you to my  other project  website https://flyemirate.lovable.app/
